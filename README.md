## 📌 Sobre o Projeto

**K-Quiz Mania** é um quiz interativo sobre Doramas, criado com HTML, CSS e JavaScript — com uma pitada de inteligência artificial via **Google AI Studio**. Um projeto feito com paixão por cultura asiática e empolgação tech.

Você escolhe uma categoria e testa seus conhecimentos sobre:
- 🎥 Cenas icônicas
- 🎭 Atores e atrizes
- 🎧 Trilhas sonoras misteriosas

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- Google AI Studio 
- Git e GitHub
- GitHub Pages (deploy)
